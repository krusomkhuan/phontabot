# น้องโพนต้า — ตอบจาก Google Sheets โดยไม่ใช้ AI

LINE chatbot งานประชาสัมพันธ์ วิทยาลัยการอาชีพโพนทอง ใช้ Next.js 14 + TypeScript และ Vercel

## การทำงาน
รับข้อความที่ /api/webhook ตรวจลายเซ็น LINE อ่าน CSV จาก Google Sheets (cache 60 วินาทีต่อ instance) แล้วค้นคำตอบจากคอลัมน์คำถาม ตอบจากคอลัมน์คำตอบโดยตรง ไม่เรียก Gemini หรือบริการ AI ไม่มีค่าใช้จ่าย Gemini จากโค้ดนี้ ค่าใช้บริการ LINE/Vercel เป็นไปตามแผนที่ใช้อยู่

รองรับคำถามตรงตัวและคำใกล้เคียงในหัวข้อเวลาเปิดทำการ ติดต่อ วันรับสมัคร เอกสารสมัคร สาขา ค่าใช้จ่าย และชมรม หากไม่มั่นใจ ข้อมูลขัดกัน หรือหลายหัวข้อ ใช้ข้อความสำรอง: ขออภัยค่ะ น้องโพนต้ายังไม่มีข้อมูลเรื่องนี้ค่ะ

เป็นการจับคู่ข้อความและกลุ่มคำ ไม่ใช่ AI จึงอาจไม่เข้าใจประโยคซับซ้อน รองรับถ้อยคำเพิ่มเติมได้โดยเพิ่มแถวคำถามใหม่และคำตอบในชีต แถวที่มีความหมายเดียวกันควรใช้คำตอบเดียวกัน

## ตั้งค่า
Node.js 22 ขึ้นไป รัน npm install, npm test, npm run build
Production ต้องมีเพียง CHANNEL_ACCESS_TOKEN, CHANNEL_SECRET, SHEET_CSV_URL
ไม่อ่าน Gemini_API_KEY หรือ Gemimi_API_KEY อีกแล้ว ไม่จำเป็นต้องแก้หรือลบคีย์เดิมเพื่อใช้งาน

หัวคอลัมน์ชีต: หมวดหมู่, คำถาม, คำตอบ เผยแพร่ CSV สาธารณะ รองรับ comma และข้อความหลายบรรทัด ข้ามแถวที่ไม่มีคำถามหรือคำตอบ เมื่อดึงชีตล้มเหลวใช้ข้อความสำรอง ไม่ใช้ cache หมดอายุ

## Deploy
Vercel โปรเจกต์ phonta เชื่อม GitHub krusomkhuan/phontabot ใช้ Framework Next.js และ Root Directory ว่าง
LINE Webhook URL: https://phonta.vercel.app/api/webhook เปิด Use webhook แล้วกด Verify
ทดสอบข้อความจริงหลัง Deploy เช่น วิทยาลัยเปิดทำการกี่โมง / สมัครเรียนใช้เอกสารอะไรบ้าง / เบอร์โทรวิทยาลัย / มีหอพักไหม

Logs service=faq แสดง rows และ matched โดยไม่บันทึกข้อความผู้ใช้หรือค่าลับ
Tests ครอบคลุมลายเซ็น CSV ภาษาไทย การจับคำใกล้เคียง ข้อมูลขัดแย้ง คำถามนอกขอบเขต และการตอบผ่าน LINE SDK โดยไม่มีคีย์ AI และไม่มีคำขอไปบริการ AI
ไม่มีประวัติผู้ใช้หรือระบบป้องกัน event ซ้ำข้าม instance ควรปิด Webhook redelivery จนเพิ่มระบบป้องกันซ้ำถาวร

## บันทึกคำถามที่ตอบไม่ได้ + สรุป LINE รายวัน

เพิ่มตัวรับ Google Apps Script ใน google-apps-script/Code.gs พร้อมคู่มือตั้งค่า SETUP.md
เก็บคำถามในไฟล์ส่วนตัวแยกจาก FAQ สาธารณะ รวมคำถามที่ข้อความตรงกันหลังปรับช่องว่าง/เครื่องหมาย นับจำนวนครั้ง วันเวลา สถานะ และสาเหตุ no_match/system_error
ตั้ง UNANSWERED_LOG_URL และ UNANSWERED_LOG_SECRET ใน Vercel จึงจะเริ่มบันทึก ถ้ายังไม่ตั้ง ระบบตอบ FAQ ทำงานเหมือนเดิมและ Logs แสดง not_configured
สรุปเข้ากลุ่มวันละครั้งประมาณ 08:00–09:00 น. เวลาไทย เป็นข้อมูลวันก่อนหน้า ตั้ง Script properties และรัน installDailySummary ตามคู่มือก่อน
พิมพ์ /group-id ในกลุ่มเพื่อดูรหัสสำหรับตั้งค่า ไม่ผูกกลุ่มตามชื่อ และไม่เก็บบทสนทนาภายในกลุ่ม
กันนับซ้ำเฉพาะบันทึกเหตุการณ์ด้วยรหัสถาวรในชีต ไม่ได้กันส่ง reply ซ้ำทั้งระบบ; ไม่ควรเปิด redelivery โดยไม่มีการประเมินเพิ่มเติม
ไม่ส่งชื่อ/LINE user ID ปิดบังอีเมลและหมายเลขยาวแบบ best effort; ใช้ไฟล์ส่วนตัวเพราะข้อความอาจยังมีข้อมูลส่วนบุคคล
ผ่านการทดสอบจำลอง atomic update, redelivery, ลายเซ็นผิด, retry, แยกข้อผิดพลาด, สรุปไม่ส่งซ้ำ ต้องทดสอบเชื่อมต่อ Google และ LINE จริงหลังตั้งค่า

ผู้ดูแลที่ระบุ ADMIN_USER_IDS และอยู่ใน ADMIN_GROUP_ID ใช้ /คำถามค้าง และ /ตอบ รหัส | คำถาม FAQ | คำตอบ เพื่อเพิ่มแถว Google Sheet FAQ เดิมและปิดรายการได้ ต้องตั้งค่า allowlist ทั้ง Vercel และ Apps Script; ตรวจทั้งกลุ่มและบัญชีจาก webhook ที่ผ่านลายเซ็น LINE สมาชิกทั่วไปในกลุ่มไม่มีสิทธิ์เขียนผ่านบอท รหัสของตนเองดูด้วย /my-id ในกลุ่มหรือแชตส่วนตัว การตอบผ่านกลุ่มเผยแพร่ FAQ จึงต้องตรวจข้อเท็จจริงและข้อมูลส่วนบุคคลก่อนส่ง

## แบบฟอร์มมือถือ
ส่ง /คำถามค้าง ในกลุ่มด้วยบัญชีผู้ดูแล จะได้ลิงก์เฉพาะรายการ อายุ 30 นาที เปิดกรอกคำถาม FAQ และคำตอบได้จากสมาร์ทโฟน โดยไม่ต้องพิมพ์คำสั่งยาว
ลิงก์ใช้สร้างร่างได้เท่านั้น ผู้ดูแลคนเดิมต้องกดยืนยันเพิ่มคำตอบใน LINE ผ่าน postback ที่ตรวจลายเซ็น กลุ่ม และบัญชีอีกครั้ง จึงจะเขียน FAQ ผู้ถือหรือผู้รับต่อลิงก์ไม่มีสิทธิ์เผยแพร่ด้วยลิงก์เพียงอย่างเดียว ร่างเก็บในแท็บส่วนตัว ร่างคำตอบ และไม่บันทึกซ้ำเมื่อกดยืนยันซ้ำ
ใช้ /สรุปวันนี้ ดูจำนวนวันนี้ได้ ส่วนสรุปอัตโนมัติส่งทุกเช้าประมาณ 08:00–09:00 เวลาไทย รวมวันที่ไม่มีเหตุการณ์ด้วย พร้อมปุ่ม ดูคำถามค้าง
หลังแก้ Apps Script ต้องอัปเดตเวอร์ชัน deployment เดิมด้วย อย่าเปลี่ยนสิทธิ์แชร์ชีตบันทึกเป็นสาธารณะ
